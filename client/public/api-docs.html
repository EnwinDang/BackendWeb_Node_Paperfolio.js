Products & Categories API

RESTful API documentatie voor het beheren van producten en categorieën

Overzicht

Deze API biedt volledige CRUD (Create, Read, Update, Delete) functionaliteit voor twee entiteiten: Categorieën en Producten. De API volgt RESTful conventies en gebruikt JSON voor data uitwisseling.

Base URL: /api

Kenmerken

  • Volledige CRUD operaties voor Categorieën en Producten
  • Paginatie ondersteuning met limit en offset parameters
  • Zoekfunctionaliteit op meerdere velden
  • Uitgebreide validatie van invoergegevens
  • Consistente JSON response structuur

Response Structuur

Alle responses volgen een consistente structuur:

{
    "success": true|false,
    "data": { ... } | [ ... ],
    "message": "Optioneel bericht",
    "errors": [ { "field": "...", "message": "..." } ]
}

Categorieën Endpoints

GET /api/categories

Haal alle categorieën op

Response:

{
    "success": true,
    "data": [
        {
            "id": 1,
            "name": "Elektronica",
            "description": "Elektronische apparaten",
            "createdAt": "2024-01-01T00:00:00.000Z",
            "updatedAt": "2024-01-01T00:00:00.000Z"
        }
    ],
    "count": 1
}
GET /api/categories/paginated

Haal categorieën op met paginatie

Query Parameters:

Parameter Type Vereist Beschrijving
limit integer Optioneel Aantal resultaten per pagina (standaard: 10)
offset integer Optioneel Aantal resultaten om over te slaan (standaard: 0)

Voorbeeld:

GET /api/categories/paginated?limit=5&offset=10
GET /api/categories/search

Zoek categorieën op naam of beschrijving

Query Parameters:

Parameter Type Vereist Beschrijving
q string Verplicht Zoekterm

Voorbeeld:

GET /api/categories/search?q=elektronica
GET /api/categories/:id

Haal een specifieke categorie op

URL Parameters:

Parameter Type Beschrijving
id integer Categorie ID
POST /api/categories

Maak een nieuwe categorie aan

Request Body:

Veld Type Vereist Validatie
name string Verplicht Mag niet leeg zijn, geen cijfers toegestaan
description string Optioneel -

Voorbeeld Request:

{
    "name": "Elektronica",
    "description": "Alle elektronische apparaten"
}
PUT /api/categories/:id

Update een categorie volledig (alle velden vereist)

Request Body:

Zelfde als POST, alle velden zijn vereist

PATCH /api/categories/:id

Update een categorie gedeeltelijk (alleen opgegeven velden)

Request Body:

Alleen de velden die gewijzigd moeten worden

DELETE /api/categories/:id

Verwijder een categorie

Producten Endpoints

GET /api/products

Haal alle producten op

Response:

{
    "success": true,
    "data": [
        {
            "id": 1,
            "name": "Laptop",
            "description": "Krachtige laptop",
            "price": "999.99",
            "stock": 50,
            "categoryId": 1,
            "createdAt": "2024-01-01T00:00:00.000Z",
            "updatedAt": "2024-01-01T00:00:00.000Z"
        }
    ],
    "count": 1
}
GET /api/products/paginated

Haal producten op met paginatie

Query Parameters:

Parameter Type Vereist Beschrijving
limit integer Optioneel Aantal resultaten per pagina (standaard: 10)
offset integer Optioneel Aantal resultaten om over te slaan (standaard: 0)
GET /api/products/search

Zoek producten op naam, beschrijving en optioneel categorie

Query Parameters:

Parameter Type Vereist Beschrijving
q string Verplicht Zoekterm
categoryId integer Optioneel Filter op categorie ID

Voorbeeld:

GET /api/products/search?q=laptop&categoryId=1
GET /api/products/category/:categoryId

Haal alle producten van een specifieke categorie op

GET /api/products/:id

Haal een specifiek product op (inclusief categorie informatie)

POST /api/products

Maak een nieuw product aan

Request Body:

Veld Type Vereist Validatie
name string Verplicht Mag niet leeg zijn, geen cijfers toegestaan
description string Optioneel -
price number Verplicht Moet een positief getal zijn
stock integer Optioneel Moet een niet-negatief geheel getal zijn (standaard: 0)
categoryId integer Optioneel Moet verwijzen naar een bestaande categorie

Voorbeeld Request:

{
    "name": "Laptop",
    "description": "Krachtige laptop voor professionals",
    "price": 999.99,
    "stock": 50,
    "categoryId": 1
}
PUT /api/products/:id

Update een product volledig

PATCH /api/products/:id

Update een product gedeeltelijk

DELETE /api/products/:id

Verwijder een product

Validatie Regels

Algemene Regels

  • Verplichte velden mogen niet leeg zijn
  • Numerieke velden accepteren geen strings
  • Namen (categorie en product) mogen geen cijfers bevatten

Specifieke Validaties

Veld Validatie
price Moet een positief getal zijn (> 0)
stock Moet een niet-negatief geheel getal zijn (>= 0)
categoryId Moet verwijzen naar een bestaande categorie
limit Moet een positief geheel getal zijn
offset Moet een niet-negatief geheel getal zijn

HTTP Status Codes

Code Beschrijving
200 OK Succesvolle GET, PUT, PATCH of DELETE request
201 Created Succesvolle POST request (nieuwe resource aangemaakt)
400 Bad Request Ongeldige request data of validatiefout
404 Not Found Resource niet gevonden
500 Internal Server Error Server fout

Voorbeelden met cURL

Categorie aanmaken

curl -X POST http://localhost:3000/api/categories \
  -H "Content-Type: application/json" \
  -d '{"name": "Elektronica", "description": "Elektronische apparaten"}'

Producten ophalen met paginatie

curl "http://localhost:3000/api/products/paginated?limit=10&offset=0"

Product zoeken

curl "http://localhost:3000/api/products/search?q=laptop"

Product updaten

curl -X PATCH http://localhost:3000/api/products/1 \
  -H "Content-Type: application/json" \
  -d '{"price": 899.99}'

Categorie verwijderen

curl -X DELETE http://localhost:3000/api/categories/1
